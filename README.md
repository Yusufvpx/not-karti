# Not Kartı

Ders notlarından çevrilebilir çalışma kartları. iPhone, iPad, Mac ve Windows'ta çalışan bir PWA.

- Site: GitHub Pages
- Kartlar ve resimler: Supabase (`cards` tablosu, `resimler` deposu)
- Güncelleme: `app.js` içindeki `APP_VERSION` ve `version.json` birlikte artırılır; uygulama yeni sürümü kendisi bulur.
